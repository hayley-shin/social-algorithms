# Social Algorithms

Computational assignments completed for **Social Algorithms** at Yale University.

The coursework explores how computational methods can be used to study social and algorithmic systems, with assignments covering LLM-based survey simulation, social network analysis, and LLM behavior.

## Assignments

### 1. LLM Survey Simulation

Simulated survey responses using large language models and compared them with human survey responses.

- Generated synthetic survey responses using GPT
- Integrated U.S. Census demographic data
- Applied post-stratification to adjust simulated responses to population demographics
- Compared human and LLM-generated attitudes across demographic groups

**Methods & Tools:** Python, OpenAI API, Census data, post-stratification

### 2. Bluesky Network Analysis

Collected and analyzed social network and interaction data from Bluesky.

- Collected feed, follow, and reply data through the Bluesky API
- Examined similarity and recommendation patterns in social feeds
- Analyzed network structure and homophily in interactions
- Studied reply patterns involving U.S. senators and other users

**Methods & Tools:** Python, Bluesky API, social network analysis, data visualization

### 3. LLM Creativity and Model Competition

Conducted computational experiments on randomness, creativity, and strategic interaction among large language models.

- Examined how temperature and prompting strategies affect response diversity
- Evaluated LLM performance in a Scattergories-style task
- Conducted self-play experiments using the same model
- Compared behavior and performance across multiple language models
- Used an LLM-based judge to evaluate generated responses

**Methods & Tools:** Python, Jupyter Notebook, OpenAI API, Ollama, LLM experimentation
